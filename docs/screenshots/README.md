# Screenshots

The root README expects these files:

| File | Suggested shot |
|---|---|
| `multichat.png` | Two or three chat panels side by side |
| `moderation.png` | Moderation panel + custom mod buttons |
| `themes.png` | Theme editor with an accent palette open |
| `predictions.png` | Prediction banner + the bet dialog |
| `ai.png` | AI assistant panel with a reply |
| `profile.png` | User mini-profile |

Recommended width ~1200 px, PNG.
